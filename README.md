# منتجاتي

صفحة شخصية واحدة تجمع مشاريعي ومنتجاتي الرقمية: بطاقة لكل مشروع بشعاره وصورته وحالته، وأزرار فتح وGitHub ومجلد المشروع، مع روابط سريعة للمنصات والملفات.

- الملف: `index.html` (لا يحتاج بناء ولا خادم)
- البيانات: كتلة `DATA` أعلى السكربت داخل الملف
- الصور: مجلد `assets/` (شعارات ولقطات مأخوذة من صفحات المشاريع)

## التشغيل
افتح `index.html` مباشرة. عند فتحه محليًا يعمل زر «المجلد» بفتح مجلد المشروع على الجهاز، وعند نشره على الويب ينسخ المسار.
