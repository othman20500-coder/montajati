# منتجاتي

موقع شخصي بنسختين من ملف بيانات واحد لكل نسخة، بلا بناء ولا خادم:

| الملف | النسخة | لمن |
|---|---|---|
| `index.html` | التسويقية: افتتاحية، ثلاثة مسارات، خريطة أعمال تفاعلية، قصص أثر، وضعان للعرض، بحث وأوامر ⌘K، «اسأل»، الأثر بالأرقام، الآن | الزائر والشركاء |
| `office.html` | الشخصية المبسطة: بطاقات المنتجات مع أزرار فتح وGitHub ومجلد المشروع، والروابط والملفات | عثمان |
| `tasks.html` | نموذج MVP لإدارة المهام والأفكار (يومي، خط زمني، أفكار، تركيز، تقدم، مراجعة الصباح وإغلاق اليوم، استيراد تقويم .ics للقراءة) يعمل بفتح الملف مباشرة ويحفظ في المتصفح، مع تصدير واستيراد JSON | عثمان |

- الصور في `assets/` مأخوذة من صفحات المنتجات نفسها.
- تعديل المحتوى: كتلة `PROJECTS` و`SITE` في `index.html`، وكتلة `DATA` في `office.html`.
- الروابط في النسخة التسويقية مصنّفة: عام، يحتاج صلاحية، داخلي (لا يظهر للزائر).
- كل منتج له رابط مستقل بصيغة `#/p/<slug>`، وزر «حفظ PDF» يطبع صفحته فقط.

## النشر
النسخة التسويقية منشورة على https://montajati.netlify.app من `index.html` و`assets/` فقط. ملف `office.html` لا يُنشر لأنه يحوي مسارات محلية.

## دراسات
- `docs/task-management-design.md`: دراسة مقارنة لتطبيقات إدارة المهام وتصور صفحة تفاعلية شخصية (سبتمبر 2026). نموذجها الأولي في `tasks.html`.
