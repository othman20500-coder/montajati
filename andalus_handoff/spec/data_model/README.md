قواعد:
- لا إحداثيات مخترعة: أماكن بلا موقع معروف geometry = null.
- إحداثيات المدن الحالية «less-certain» لأنها مركز المدينة الحديثة لا الموقع الأندلسي الدقيق.
- أجزاء الأسماء ذات الأصل ref مأخوذة من المعرفة المرجعية العامة ويجب مطابقتها مع PUA قبل النشر.
- المعرّف https://andalus.example/ عنوان مؤقت يُستبدل بنطاق المشروع عند النشر.
