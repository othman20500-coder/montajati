# مخططات منصة الأندلس

ثلاثة مخططات بنظام [Diagram Design](https://github.com/cathrynlavery/diagram-design) (MIT) بعد تكييفه للعربية وهوية المنصة:

1. **من المصدر إلى الأطلس**: مسار البيانات حتى التصدير الثابت، وبوابة الجودة نقطة الحسم.
2. **حالة الشاهد في المراجعة بالعين**: وفق `andalus_handoff/spec/review/README.md`.
3. **عصور الأندلس بحدودها غير القاطعة**: يُقرأ من جدول `periods` في القاعدة مباشرة.

`index.html` مولَّد؛ عدّل `build.py` أو `page.css` أو `page.template.html` ثم أعد التوليد:

```
python platform/diagrams/build.py /tmp/fragment.html platform/diagrams/index.html
```

المجلد خارج `andalus/` عمدًا: المخططات وثائق داخلية لا تُنشر على موقع الأطلس.

## التكييف العربي
- الصفحة والمخططات من اليمين، وخط الزمن داخلها من اليسار إلى اليمين (قاعدة «اللغة والواجهة» في CLAUDE.md).
- Reem Kufi للعناوين، وAmiri للحواشي التحريرية بدل Instrument Serif، وIBM Plex Sans Arabic للعقد والمتن، وIBM Plex Mono للمعرّفات والملفات فقط.
- لا أحرف كبيرة ولا تباعد بين الحروف، والخط أكبر بنقطة إلى نقطتين من الأصل.
- ألوان «الزليج» للوضع الفاتح، و«الليل الأندلسي» للداكن؛ لون التركيز العسلي على عنصر أو عنصرين.
