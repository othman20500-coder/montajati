# طبقة البيانات (MVP)

| الملف | الدور |
|---|---|
| `schema.json` | مخطط JSON Schema للكيانات والادعاءات والمصادر (المرجع المعياري) |
| `graph.js` | **مولَّد آليًا** من قاعدة v1.2 بسكربت `platform/tools/export_static.py`؛ لا يُحرَّر يدويًا. يحوي `ERAS` و`SOURCES` و`CLAIMS` (إسنادات بشواهدها) و`ENTITIES` و`STORIES` و`QUIZ` |
| `graph.prototype.js` | النموذج البحثي القديم (مستوى «ظهر في نتائج البحث»، بلا شواهد حرفية). لا يُحمَّل في الواجهة العامة؛ مرجع داخلي لتوسيع الإسنادات لاحقًا عبر مهارة `andalus-evidence` |

لماذا JavaScript لا JSON؟ لأن الصفحة تعمل من الملف مباشرة بلا خادم ولا بناء (قاعدة المستودع)، والمتصفح لا يسمح بقراءة JSON عبر `file://`. الشكل نفسه قابل للتحويل إلى JSON-LD بسطر واحد عند بناء API القراءة في المرحلة الثانية.

## كيف تضيف معلومة (بعد v1.2)

الإضافة لا تكون في `graph.js` بل في قاعدة المنصة عبر مهارة `andalus-evidence` (إسناد ← شاهد حرفي بموضعه ← ادعاء)، ثم `python platform/tools/export_static.py`. ما يلي وصف تاريخي لبنية النموذج الأولي:

## كيف كان يُضاف في النموذج الأولي

1. **أنشئ المصدر** في `SOURCES` إن لم يكن موجودًا: العنوان، المؤلف، السنة، الناشر، المرتبة (A/B/C/D)، الرابط، و`url_checked` (`fetched` فُتح مباشرة، `search` ظهر في نتائج البحث، `none`).
2. **أنشئ الادعاء** في `CLAIMS`: نص عربي بالتقويمين إن أمكن، الحالة، المصادر مع الموضع، والأقوال المخالفة إن كان مختلفًا عليه.
3. **اربطه بالكيان**: أضف `[النص, "c:المعرف"]` في `summary` أو حقل التاريخ.
4. **لا تُنشئ ادعاء «fact» بمصدر وحيد من المرتبة D** (ويكيبيديا وأشباهها)؛ ضعه `unverified` حتى يُفتح مرجع مؤسسي.

## حالات الادعاء

| الحالة | الشارة | المعنى | يظهر في |
|---|---|---|---|
| `fact` | 🟢 | مصدر A/B يدعمه بنصه ونطاقه | كل الأوضاع، الألعاب، الملخصات |
| `disputed` | 🟠 | أقوال متنافسة موثقة | كل الأوضاع مع الأقوال |
| `inference` | 🔵 | قراءة للمؤرخين لا نص صريح | كل الأوضاع موسومًا |
| `myth` | ⚪ | رواية شائعة تُذكر لتُنقد | العام والباحث |
| `unverified` | ⬜ | لم يُفتح له مرجع مؤسسي بعد | الباحث فقط؛ لا ألعاب ولا ملخصات |

## الفحص

قبل أي التزام، شغّل من مجلد `andalus`:

```bash
node -e "new Function(require('fs').readFileSync('data/graph.js','utf8'));console.log('syntax ok')"
```

وفحص الاتساق (كل حافة تشير إلى كيان موجود، كل ادعاء له مصدر موجود، لا معرّفات مكررة) موصوف في الفصل 7، ويُنفَّذ كسكربت مؤقت لا يُضاف إلى المستودع التزامًا بقاعدة «بلا أدوات بناء».
