# 4. معمارية المنصة: الشخص ← المكان ← الحدث ← العصر ← الوثيقة ← الأثر

> المبدأ الحاكم: **لا كيان بلا روابط، ولا معلومة بلا ادعاء، ولا ادعاء بلا مصدر.**
> كل صفحة في المنصة هي عقدة في شبكة، وكل جملة تاريخية فيها هي «ادعاء» له حالة (حقيقة مستقرة / رواية مختلف عليها / استنتاج) ومصدر يمكن التحقق منه.

## 4.1 لماذا شبكة لا شجرة

الموسوعات التقليدية تنظم المحتوى شجريًا (عصر ← دولة ← حاكم). لكن السؤال الحقيقي للزائر عابر للشجرة: «ماذا كان يحدث في قرطبة عندما كتب ابن حزم طوق الحمامة؟ ومن كان الحاكم؟ وأين المخطوطة اليوم؟». الإجابة تحتاج شبكة (Graph) تربط كيانات من أنواع مختلفة بعلاقات مسماة وموثقة.

المعمارية المقترحة: **رسم معرفي (Knowledge Graph) خفيف مخزَّن كملفات JSON-LD في Git**، يُبنى منه الموقع الثابت، ويُنشر منه API للقراءة. لا قاعدة بيانات في المرحلة الأولى (اتساقًا مع أسلوب العمل الذي نجح في «منتجاتي» و«فرص» و«مِراس»: ملفات ثابتة، بلا خادم، نشر على Netlify)، مع مسار واضح للانتقال إلى قاعدة رسومية عند الحاجة.

## 4.2 أنواع الكيانات (Entity Types)

| النوع | المعرّف | أمثلة | الحقول الخاصة |
|---|---|---|---|
| **Person** شخص | `p:` | عبد الرحمن الداخل، ابن رشد، ولادة بنت المستكفي | الأدوار (خليفة/فقيه/شاعر…)، النسب، الأسرة/الدولة، تواريخ الميلاد والوفاة بدرجة يقين |
| **Place** مكان | `pl:` | قرطبة، مدينة الزهراء، وادي لكة، سبتة | الإحداثيات، الأسماء عبر اللغات والعصور (قرطبة/Córdoba/Corduba)، نوع المكان (مدينة/قلعة/معلم/ميدان معركة/نهر)، الحالة اليوم |
| **Event** حدث | `e:` | معركة الزلاقة، سقوط الخلافة، تسليم غرناطة | الزمن (نقطة/مدة)، النوع (معركة/معاهدة/تأسيس/وفاة/بناء/هجرة)، الأطراف والنتيجة |
| **Era** عصر | `era:` | الولاة، الإمارة، الخلافة، الطوائف، المرابطون، الموحدون، غرناطة، الموريسكيون | بداية ونهاية، الدول المهيمنة، لون العصر في الواجهة |
| **Polity** دولة/أسرة | `s:` | الخلافة الأموية في قرطبة، بنو عبّاد، بنو نصر | العاصمة، الحكام مرتبين، العلاقة بالدول الأخرى |
| **Document** وثيقة/مخطوط/نص | `d:` | المقتبس لابن حيان، معاهدة تسليم غرناطة 1491، سجل تفتيش | النوع، اللغة، المؤلف، مكان الحفظ الحالي، الرقم المكتبي، رابط IIIF إن وُجد، التحقيق المعتمد |
| **Artifact** أثر/قطعة | `a:` | علبة المغيرة العاجية، إسطرلاب الزرقالي، جرار الحمراء | المتحف الحالي ورقم القطعة، المادة، الأبعاد، الترخيص البصري |
| **Work** مصنَّف فكري | `w:` | طوق الحمامة، التصريف للزهراوي، الجداول الطليطلية | يختلف عن الوثيقة: المصنَّف فكرة، والوثيقة نسخة مادية منه |
| **Theme** موضوع | `t:` | الزراعة، الترجمة في طليطلة، الموشحات، أهل الذمة | مدخل أفقي يجمع الكيانات عبر الأنواع |
| **Source** مرجع ببليوغرافي | `src:` | Kennedy 1996، EI2 «al-Andalus»، تحقيق المقتبس (مكي 2003) | المرتبة (A/B/C)، النوع، اللغة، الرابط، الحقوق |
| **Claim** ادعاء | `c:` | «تولى عبد الرحمن الثالث الإمارة سنة 300هـ/912م» | النص، الحالة، المصادر مع المواضع، الأقوال المخالفة، المراجع البشري، تاريخ المراجعة |
| **Story** رحلة سردية | `st:` | «رحلة ابن جبير»، «يوم سقطت الخلافة» | تسلسل مشاهد، كل مشهد يشير إلى كيان وزمن ومكان |
| **Media** وسائط | `m:` | صورة، صوت، نموذج ثلاثي الأبعاد | المصدر، الترخيص، الوصف البديل، الكيانات المرتبطة |

## 4.3 العلاقات (Edges)

العلاقات موجهة ومسماة، وكل علاقة يمكن أن تحمل زمنًا ومصدرًا:

```
Person  --ruled-->            Polity        (from, to, claim)
Person  --born_in / died_in--> Place        (date, claim)
Person  --lived_in-->         Place         (from, to)
Person  --participated_in-->  Event         (role: قائد/طرف/شاهد)
Person  --authored-->         Work
Person  --teacher_of / student_of--> Person   (سلاسل الإسناد والتلمذة)
Person  --patron_of-->        Person | Work | Place
Work    --attested_in-->      Document      (نسخة مخطوطة أو طبعة)
Document --held_at-->         Place         (المكتبة/الأرشيف)
Artifact --held_at-->         Place         (المتحف)
Artifact --made_in-->         Place         (ورشة/مدينة)
Artifact --commissioned_by--> Person
Event   --took_place_at-->    Place
Event   --part_of-->          Era | Event   (حملة ضمن حرب)
Event   --caused / followed--> Event         (استنتاج غالبًا: يُوسم كذلك)
Place   --part_of-->          Place         (حي ← مدينة ← كورة)
Place   --controlled_by-->    Polity        (from, to)   ← أساس الخريطة الزمنية
Polity  --succeeded_by-->     Polity
Any     --mentioned_in-->     Document | Source
Any     --same_as-->          Wikidata QID | Pleiades | VIAF | Getty TGN/ULAN
```

القاعدة: **كل صفحة كيان تعرض تلقائيًا كل الحواف الداخلة والخارجة**، مجمّعة بحسب النوع. فصفحة «قرطبة» تعرض: مَن وُلد فيها، مَن حكمها، ما جرى فيها، ما كُتب فيها، ما بقي منها في المتاحف، وما قيل عنها في المصادر. هذا هو «الاستكشاف المتبادل» عمليًا.

## 4.4 نموذج الزمن

- كل تاريخ يُخزّن بصيغتين: **هجري وميلادي**، مع **درجة يقين**: `exact` / `circa` / `range` / `terminus_post` / `terminus_ante` / `disputed`.
- الخريطة الزمنية تستهلك علاقات `controlled_by(from,to)` لتلوين المناطق في أي سنة.
- سنة الواجهة الافتراضية ميلادية، ويظهر الهجري بجانبها دائمًا (خبرة «مُهلة» في التقويمين تُعاد هنا).

```json
{ "date": { "greg": "1086-10-23", "hijri": "479-01-12", "precision": "exact", "claim": "c:zallaqa-date" } }
```

## 4.5 نموذج الادعاء والمصدر (قلب الموثوقية)

```json
{
  "id": "c:abd-rahman-iii-caliph-929",
  "text": "أعلن عبد الرحمن الثالث نفسه خليفة وتلقّب بأمير المؤمنين سنة 316هـ/929م.",
  "status": "fact",
  "sources": [
    { "src": "src:kennedy-1996", "locator": "الفصل الرابع", "quote": "..." },
    { "src": "src:ei2-abd-al-rahman-iii", "locator": "المدخل", "quote": "..." }
  ],
  "counter": [],
  "review": { "by": "reviewer:historian-1", "on": "2026-09-21", "tier": "A" },
  "history": [ { "on": "2026-09-21", "change": "إنشاء" } ]
}
```

- `status` ∈ { `fact` حقيقة مستقرة، `disputed` رواية مختلف عليها، `inference` استنتاج، `myth` رواية شائعة غير مثبتة }.
- الادعاء المختلف عليه **يجب** أن يحمل `counter[]`: الأقوال المخالفة مع مصادرها. الخلاف محتوى لا عيب.
- لا يُنشر ادعاء بلا مصدر من المرتبة A أو B. المرتبة C (مراجع عامة) تُقبل للتواريخ غير المتنازع عليها فقط. المرتبة D (مدونات، مواقع مجهولة) مرفوضة.
- على الواجهة: كل جملة موثقة تحمل شارة صغيرة (🟢 🟠 🔵 ⚪) وعند النقر تفتح لوحة **«كيف نعرف هذا؟»** تعرض المصدر والمقتطف والمراجع البشري.

## 4.6 المواءمة مع المعايير العالمية

| المعيار | الاستخدام في المنصة |
|---|---|
| **JSON-LD + schema.org** (Person/Place/Event/CreativeWork) | صيغة التخزين والنشر، فهرسة محركات البحث |
| **CIDOC-CRM** | خريطة مفاهيمية لربط الأثر والوثيقة والحدث بلغة المتاحف |
| **IIIF** (Image + Presentation API) | عرض المخطوطات والقطع من المكتبات التي تدعمه دون نسخها |
| **Linked Places / Pleiades / Getty TGN** | معرّفات الأماكن ومطابقة الأسماء التاريخية |
| **Wikidata QID / VIAF / Getty ULAN** | معرّفات الأشخاص، لربط المنصة بالويب الدلالي |
| **TEI** | ترميز النصوص الأولية المحققة عند نشر مقتطفات |
| **Hijri/Gregorian ISO 8601 + EDTF** | تمثيل التواريخ غير المؤكدة (Extended Date/Time Format) |
| **CC BY 4.0** للنصوص، **CC0** للبيانات، احترام رخص الوسائط | سياسة النشر المفتوح |

## 4.7 طبقات النظام

```
┌──────────────────────────────────────────────────────────────┐
│ التجربة: خريطة زمنية · Timeline · صفحات الكيانات · الرحلات    │
│          · المتحف · وضع الأطفال · وضع الباحث · البحث ⌘K       │
├──────────────────────────────────────────────────────────────┤
│ الواجهة: HTML/CSS/JS ثابت (MVP) · RTL أولًا · EN/ES لاحقًا      │
│          MapLibre GL (خرائط) · OpenSeadragon/Mirador (IIIF)   │
├──────────────────────────────────────────────────────────────┤
│ الرسم المعرفي: JSON-LD في Git · فهارس مبنية مسبقًا             │
│          (بحث، خريطة زمنية، مسارات) · API قراءة ثابت /api/*   │
├──────────────────────────────────────────────────────────────┤
│ التحرير والتحقق: مسار Git (اقتراح → مراجعة → اعتماد) ·         │
│          سجل الادعاءات · فحص آلي (لا ادعاء بلا مصدر)           │
├──────────────────────────────────────────────────────────────┤
│ المصادر الخارجية: IIIF من المكتبات · Met/Europeana API ·      │
│          Wikidata · Pleiades · المتاحف الشريكة                 │
└──────────────────────────────────────────────────────────────┘
```

**المرحلة الأولى (MVP)**: كل شيء ثابت. البيانات في `data/*.json`، البناء بسكربت واحد يولّد الصفحات والفهارس، النشر على Netlify. لا خادم.
**المرحلة الثانية**: طبقة API قراءة (Serverless) + محرر محتوى Git-based (مثل Decap CMS) لفريق التحرير غير التقني.
**المرحلة الثالثة**: قاعدة رسومية (Neo4j أو RDF store) عندما يتجاوز الرسم عشرات آلاف العقد، مع بقاء Git مصدر الحقيقة.

## 4.8 الاستكشاف المتبادل: كيف يبدو للزائر

1. يفتح الزائر **معركة الزلاقة (1086)**.
2. يرى الشريط الأعلى: العصر (المرابطون ← بداية)، السنة 479هـ/1086م، المكان على خريطة مصغرة.
3. يرى الأطراف: يوسف بن تاشفين، المعتمد بن عبّاد، ألفونسو السادس — كل اسم بطاقة تنقله لصفحة الشخص.
4. يرى «ماذا كان قبلها وبعدها»: سقوط طليطلة 1085 ← الزلاقة ← ضم المرابطين للطوائف.
5. يرى «المصادر التي تروي المعركة»: الحلل الموشية، البيان المغرب، وأعمال حديثة — مع تنبيه أن أرقام الجيوش رواية مختلف عليها.
6. يرى «ما بقي»: لا آثار مادية مباشرة، لكن موقع المعركة (بطليوس) على الخريطة الحالية.
7. من أي عنصر يمكن القفز: المعتمد ← إشبيلية ← القصر ← الشعر ← ابن زيدون ← قرطبة ← …

هذه الحلقة هي المنتج. كل ما عداها (الألعاب، القصص، الفيديو) طبقات فوقها.
