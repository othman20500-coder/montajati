# 6. الهوية البصرية ونظام التصميم والـWireframes

## 6.1 ثلاثة اتجاهات بصرية

الاتجاهات الثلاثة مبنية في النموذج التفاعلي `index.html` كسمات (Themes) قابلة للتبديل من الترويسة، لتُقارن على الشاشة لا على الورق.

### الاتجاه أ: «المخطوط» (The Manuscript)

| البند | القرار |
|---|---|
| الفكرة | المنصة كمخطوط مفتوح: ورق دافئ، حبر أسمر، ذهب مطفأ، وهوامش واسعة كهوامش الحواشي. |
| الألوان | ورق `#F4ECDC` · حبر `#2B1D12` · ذهب `#B5893A` · أزرق مغربي للروابط `#1F4E79` · أحمر شنجرفي للعناوين الفرعية `#9B2D20` |
| الخط | عناوين: **Amiri** أو **Scheherazade New** (روح النسخ المغربي) · متن: **Noto Naskh Arabic** · لاتيني: **Cormorant Garamond** |
| الزخرفة | إطار هندسي رفيع حول الصور، فواصل من زخرفة نباتية مبسطة، لا أنماط ثقيلة. |
| الحركة | بطيئة، انزلاقية، كتقليب صفحة. |
| يناسب | وضع الباحث، الوثائق، المخطوطات، الطابع الأكاديمي. |
| الخطر | قد يبدو «قديمًا» للجيل الأصغر إن لم تُضبط الحداثة في التخطيط. |

### الاتجاه ب: «الزليج» (The Zellij)

| البند | القرار |
|---|---|
| الفكرة | الهندسة الأندلسية بلغة معاصرة: شبكات حادة، ألوان الخزف (أزرق كوبالت، فيروزي، أبيض قصديري، أصفر عسلي). |
| الألوان | أبيض قصديري `#F7F5EF` · كوبالت `#173F7A` · فيروزي `#1E9C8B` · عسلي `#E4B33B` · حبر `#14202E` |
| الخط | عناوين: **Reem Kufi** أو **Cairo** (كوفي هندسي) · متن: **IBM Plex Sans Arabic** · لاتيني: **Inter** |
| الزخرفة | نمط نجمي ثماني بشفافية 4% في الخلفيات، بطاقات بزوايا مقطوعة قطعًا هندسيًا. |
| الحركة | سريعة ودقيقة، تحوّلات نمطية (Tessellation morph) بين العصور. |
| يناسب | الأطفال، الألعاب، الخريطة الزمنية، الجمهور العام. |
| الخطر | الإفراط في الزخرفة يشوش على المحتوى؛ الحد الأقصى عنصر زخرفي واحد لكل شاشة. |

### الاتجاه ج: «الليل الأندلسي» (Andalusian Night)

| البند | القرار |
|---|---|
| الفكرة | تجربة سينمائية غامرة: خلفيات داكنة كسماء غرناطة، إضاءة نحاسية كمصابيح الزيت، صور فوتوغرافية كبيرة. |
| الألوان | ليل `#0E1420` · نحاس `#C77D3A` · ضوء القمر `#DCE3EA` · زيتون `#4E6B4A` · خط فاصل `#26303F` |
| الخط | عناوين: **Aref Ruqaa** (لمسة خطية) بحجم كبير جدًا فقط، أو **Tajawal** · متن: **Tajawal** · لاتيني: **Playfair Display** |
| الزخرفة | لا زخرفة؛ الصورة والفراغ والظل. المقرنصات تظهر كإضاءة لا كرسم. |
| الحركة | Scrollytelling، Parallax خفيف، تلاشي بين المشاهد. |
| يناسب | القصص، الخط الزمني السينمائي، الصفحة الرئيسية، الفيديو. |
| الخطر | قابلية القراءة للنصوص الطويلة في الوضع الداكن؛ يُعالج بوضع فاتح للمقالات. |

### التوصية

**نظام هجين بقاعدة «الزليج» وسطحين**: الزليج للهيكل والمكوّنات (وضوح، حداثة، أطفال وعامة)، و«الليل الأندلسي» كسمة للقصص والصفحة الرئيسية، و«المخطوط» كسمة لوضع الباحث وصفحات الوثائق. السمة تتغير بحسب السياق لا بحسب ذوق الزائر فقط، وهو ما يجعل الانتقال من القصة إلى المصدر انتقالًا محسوسًا: من الليل إلى الورق.

## 6.2 نظام التصميم (Design System)

### الرموز (Tokens)

```css
:root{
  /* الألوان الوظيفية (ثابتة عبر السمات) */
  --fact:#1F9D6A;      /* حقيقة مستقرة */
  --disputed:#D08A1E;  /* رواية مختلف عليها */
  --inference:#3F6FB5; /* استنتاج */
  --myth:#8A8F98;      /* رواية شائعة غير مثبتة */
  /* ألوان العصور (ثابتة عبر السمات، تُستخدم في الخريطة والخط الزمني) */
  --era-wulat:#8C6D3F; --era-imara:#2E7D5B; --era-khilafa:#1F5FA8;
  --era-tawaif:#B2632B; --era-murabit:#5B3F8C; --era-muwahhid:#8C2F39;
  --era-nasrid:#B8912E; --era-morisco:#5C6B73;
  /* المقاييس */
  --space-1:4px; --space-2:8px; --space-3:12px; --space-4:16px; --space-6:24px; --space-8:32px; --space-12:48px;
  --radius-s:8px; --radius-m:14px; --radius-l:24px;
  --fs-xs:12.5px; --fs-s:14px; --fs-m:16px; --fs-l:19px; --fs-xl:28px; --fs-2xl:clamp(34px,6vw,60px);
  --lh-body:1.85; --lh-head:1.3;
  --ease:cubic-bezier(.2,.7,.2,1);
}
```

### المكوّنات الأساسية

| المكوّن | الوصف | القاعدة |
|---|---|---|
| **EntityCard** | بطاقة كيان: أيقونة النوع، الاسم، السنوات بالتقويمين، سطر، شارات الحالة | تُستخدم لكل نوع؛ اللون الثانوي من نوع الكيان |
| **ClaimBadge** | شارة 🟢🟠🔵⚪ بجانب الجملة | النقر يفتح **ProvenancePanel** |
| **ProvenancePanel** | لوحة «كيف نعرف هذا؟»: المصدر، المقتطف، الموضع، المراجع، تاريخ المراجعة، الأقوال المخالفة | لا تُغلق دون عرض مصدر واحد على الأقل |
| **EraRibbon** | شريط أعلى الصفحة يبيّن العصر والسنة والموقع الزمني | ثابت في كل صفحة كيان |
| **TimeSlider** | شريط الزمن 711–1614 مع علامات العصور | يُزامن الخريطة والقوائم |
| **DualDate** | «479هـ / 1086م» مع درجة اليقين (≈ ، ما بين) | لا تاريخ بتقويم واحد |
| **RelationRail** | قضبان الروابط: «الأشخاص»، «الأماكن»، «الأحداث»، «الوثائق»، «الآثار» | تُولَّد من الحواف تلقائيًا |
| **SourceChip** | رقاقة مرجع صغيرة بالمرتبة (A/B/C) | قابلة للنسخ كاستشهاد |
| **MapPin** | دبوس بلون نوع الكيان وحجم يعكس الأهمية | يحمل السنة |
| **StoryScene** | مشهد شاشة كاملة: صورة/خريطة + نص + زمن | Scroll snap |
| **AudienceSwitch** | مفتاح: استكشاف / عام / باحث | يحفظ التفضيل محليًا |
| **NameStack** | الاسم بالعربية واللاتينية والإسبانية الحالية | للأماكن والأشخاص |

### الوصول والشمول

- RTL أولًا، مع عكس تلقائي للأيقونات الاتجاهية عند EN/ES.
- تباين AA على الأقل لكل السمات، ويُختبر الليل الأندلسي بعناية.
- كل خريطة لها بديل نصي (قائمة الأماكن بحسب السنة).
- احترام `prefers-reduced-motion`: يتحول Scrollytelling إلى صفحات ثابتة.
- الحد الأدنى للمس 44px، والألعاب تعمل بلوحة المفاتيح.

## 6.3 الـWireframes

النسخة القابلة للتفاعل في `index.html`. هنا الهيكل النصي.

### الصفحة الرئيسية

```
┌───────────────────────────────────────────────────────────────┐
│ [الشعار]   الخريطة  الزمن  الأشخاص  الأماكن  المتحف  القصص  [⌘K] [استكشاف|عام|باحث] │
├───────────────────────────────────────────────────────────────┤
│  خلفية: خريطة الأندلس حيّة تتلون مع شريط الزمن                    │
│  H1: «قِف في الأندلس، في أي سنة تختار»                              │
│  ═══════ شريط الزمن 711 ─────●───── 1614 ═══════  السنة: 1010م/400هـ │
│  [ماذا كان يحدث سنة 1010؟] ← بطاقة الحدث الأقرب + الحاكم + مدينة   │
├───────────────────────────────────────────────────────────────┤
│  ثلاثة مداخل:  [رحلة سردية]   [استكشف الخريطة]   [ابحث في المصادر]  │
├───────────────────────────────────────────────────────────────┤
│  «هذا الأسبوع»: كيان مختار · وثيقة مختارة · أثر مختار                │
├───────────────────────────────────────────────────────────────┤
│  العصور الثمانية كشرائط ملونة قابلة للنقر                            │
├───────────────────────────────────────────────────────────────┤
│  كيف نتحقق؟ (شرح شارات الحالة) · الشركاء · عن المشروع               │
└───────────────────────────────────────────────────────────────┘
```

### صفحة مدينة (مثال: قرطبة)

```
┌───────────────────────────────────────────────────────────────┐
│ EraRibbon: تعرض الآن سنة ● 960م/349هـ (الخلافة) — [غيّر السنة]     │
├─────────────────────────────┬─────────────────────────────────┤
│ NameStack: قرطبة · Corduba   │ خريطة مصغرة + مخطط المدينة في     │
│ · Córdoba                    │ السنة المختارة (المسجد، الزهراء)  │
│ الملخص (كل جملة بشارة)        │                                   │
│ الحالة اليوم: مدينة إسبانية،  │ صور الآثار (IIIF/CC) مع الترخيص   │
│ تراث عالمي 1984 🟢            │                                   │
├─────────────────────────────┴─────────────────────────────────┤
│ شريط زمن المدينة: تأسيس الإمارة 756 · الجامع 785 · الزهراء 936 ·  │
│ الفتنة 1009 · الدخول القشتالي 1236 …                               │
├───────────────────────────────────────────────────────────────┤
│ RelationRail:                                                    │
│  الأشخاص (وُلد/عاش/حكم هنا)  │ الأحداث │ الوثائق التي كُتبت هنا │ الآثار │
├───────────────────────────────────────────────────────────────┤
│ الخلافات والأساطير: «مكتبة الحكم 400 ألف مجلد» ⚪ رواية شائعة …    │
├───────────────────────────────────────────────────────────────┤
│ المصادر (SourceChips) · اقترح تصحيحًا · صدّر JSON/BibTeX             │
└───────────────────────────────────────────────────────────────┘
```

### صفحة شخصية (مثال: ابن حزم)

```
┌───────────────────────────────────────────────────────────────┐
│ EraRibbon: الخلافة ← الفتنة ← الطوائف (384–456هـ / 994–1064م)      │
├─────────────────────────────┬─────────────────────────────────┤
│ الاسم الكامل · الأدوار: فقيه، │ خريطة مسار الحياة: قرطبة ← ألمرية │
│ أديب، مؤرخ                    │ ← شاطبة ← ميورقة ← منت ليشم       │
│ الملخص بشارات                 │                                   │
├─────────────────────────────┴─────────────────────────────────┤
│ خط حياته على شريط الزمن مع الأحداث السياسية المتزامنة فوقه         │
├───────────────────────────────────────────────────────────────┤
│ RelationRail: الشيوخ والتلاميذ (شبكة) │ المصنفات │ المخطوطات الباقية │ الأماكن │
├───────────────────────────────────────────────────────────────┤
│ مقتطف صوتي من نص له (إن وُجد) · سياق العصر · الخلافات حول سيرته     │
├───────────────────────────────────────────────────────────────┤
│ المصادر · المعرّفات (Wikidata, VIAF, PUA) · صدّر                     │
└───────────────────────────────────────────────────────────────┘
```
