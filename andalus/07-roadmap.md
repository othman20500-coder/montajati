## 7.4 أولويات المحتوى (ترتيب الإنتاج)

1. **العمود الفقري**: العصور والدول والحكام بتواريخ موثقة (قابل للتحقق سريعًا، ويشغّل الخريطة والخط الزمني).
2. **المدن الكبرى**: قرطبة، إشبيلية، غرناطة، طليطلة، سرقسطة، مالقة، ألمرية، بلنسية.
3. **الأحداث المفصلية**: 30 حدثًا تحدد شكل الخط الزمني.
4. **العلماء والأدباء**: بحسب توفر التراجم الأكاديمية الموثقة (PUA، DB~e، EI).
5. **الآثار المرخصة**: ما تتيحه المتاحف بترخيص مفتوح أولًا.
6. **الوثائق والمخطوطات**: ما له IIIF أولًا.
7. **الخلافات والأساطير**: تُكتب مع كل كيان لا في قسم منفصل.

## 7.5 أولويات التقنية

1. نموذج البيانات والفحص الآلي (قبل أي واجهة).
2. مولّد الصفحات والبحث.
3. الخريطة الزمنية.
4. لوحة المصدر وشارات الحالة.
5. الخط الزمني.
6. القصص والألعاب.
7. IIIF والوسائط.

## 7.6 نموذج إدارة المصادر والتحقق العلمي

### مراتب المصادر

| المرتبة | الوصف | الاستخدام |
|---|---|---|
| **A** | تحقيق علمي لنص أولي · كتاب أو مقال محكّم · موسوعة أكاديمية (EI2/EI3، DB~e) | أي ادعاء |
| **B** | مؤسسة وطنية: مكتبة، أرشيف، متحف، UNESCO، جامعة | أي ادعاء، مع تفضيل A للخلافي |
| **C** | مرجع عام موثوق (Britannica) · ويكيبيديا كدليل للوصول إلى A/B فقط | التواريخ غير الخلافية فقط، ولا يُستشهد بويكيبيديا |
| **D** | مدونات، مواقع مجهولة، فيديوهات غير مؤسسية، محتوى مولّد | مرفوض |

### دورة الادعاء

```
اقتراح (محرر) → توثيق (باحث مصادر: مصدر + مقتطف + موضع)
  → فحص النطاق (هل المصدر يقول هذا بالضبط؟ لا أوسع ولا أقوى)
  → تصنيف الحالة (fact / disputed / inference / myth)
  → مراجعة علمية (مؤرخ) → نشر بشارة
  → مراقبة (بلاغات القراء، مصادر جديدة) → تحديث موثق في History
```

### القواعد الملزمة

1. معرفة الكاتب أو النموذج اللغوي ليست مصدرًا.
2. الادعاء لا يكون أقوى من مصدره ولا أوسع نطاقًا منه (التعميم، رفع الدرجة، حذف القيود = رفض).
3. المختلف عليه يُنشر بأقواله كلها أو لا يُنشر.
4. الأرقام (أعداد الجيوش، السكان، المجلدات) تُعرض كمدى بمصادره، لا كرقم واحد.
5. كل تعديل يترك أثرًا (Git) وكل صفحة تعرض تاريخ آخر مراجعة.
6. الأسطورة الشائعة تُذكر صراحة بوصفها كذلك مع نقدها ومصدر النقد؛ الصمت عنها يترك الفراغ للمواقع غير الموثوقة.
7. الصور والوسائط: لا شيء يُنشر بلا ترخيص واضح ونسبة.

### الأدوار

| الدور | المسؤولية |
|---|---|
| المحرر الرئيس | خط التحرير، اعتماد النشر |
| باحث المصادر | التوثيق، سجل الادعاءات، فحص الروابط |
| المراجع العلمي | مؤرخ متخصص لكل عصر، مراجعة دورية |
| مطوّر البيانات | الفحص الآلي، المعرّفات، المواءمة |
| مجلس استشاري | باحثون من إسبانيا والمغرب والمشرق والغرب، يراجعون المنهجية سنويًا |

## 7.7 ما يجعل المشروع مرجعًا عالميًا لا موقع معلومات

1. **الشفافية المعرفية**: كل جملة تحمل حالتها ومصدرها، ويمكن لأي قارئ فتح «كيف نعرف هذا؟». هذا نادر حتى في المنصات الكبرى.
2. **الخلاف محتوى**: المنصة الوحيدة التي تعرض القراءات المتنافسة جنبًا إلى جنب (الفتح، التعايش، الأعداد) بدل رأي واحد.
3. **الزمن كواجهة**: خريطة وخط زمني وصفحات مترابطة بسنة واحدة مشتركة.
4. **بيانات مفتوحة وقابلة للربط**: معرّفات دائمة، JSON-LD، مواءمة Wikidata/Pleiades/IIIF، فيستفيد منها الباحثون وتُستشهد بها.
5. **العربية أولًا بجودة عالمية**: أغلب المصادر الرقمية الجادة عن الأندلس بالإسبانية والإنجليزية؛ عربية دقيقة وحديثة فجوة حقيقية.
6. **ثلاث جماهير في منصة واحدة**: الطفل والعام والباحث، من البيانات نفسها.
7. **حوكمة علنية**: سياسة تحرير، مجلس علمي، سجل تصحيحات.
8. **شراكات مؤسسية** بدل النسخ: IIIF من المكتبات، وتراخيص المتاحف، ومراجعة الجامعات.
9. **الاستدامة**: ثابت، رخيص التشغيل، مفتوح المصدر، وقابل للأرشفة الدائمة.

## 7.8 المخاطر وكيف نديرها

| الخطر | المعالجة |
|---|---|
| الانجرار إلى السرد الأيديولوجي (تمجيد أو تشويه) | نموذج الادعاء، مجلس متنوع، عرض الخلاف |
| حقوق الصور والمخطوطات | IIIF والتراخيص المفتوحة أولًا، وسياسة نشر مكتوبة |
| اتساع النطاق قبل العمق | شريحة MVP الرأسية ومعايير نجاح صارمة |
| ضعف العربية في الواجهات الأكاديمية | RTL أولًا، اختبار مع باحثين عرب |
| الاعتماد على تقنيات ثقيلة | ثابت أولًا، والتعقيد يُضاف عند الحاجة فقط |
